# To Catch a Star

## Repository
https://github.com/Em096/Final_Project.git

## Description
To Catch a Star is a game where you play as a shooting star and must collect bits of stardust to increase your score, all while avoiding asteroids.
It's relevant to media and digital arts because it's an interactive game that will use my own drawings as assets, and will be usable beyond this course.

## Features
- Feature 1: Scrolling background
  - Will need to create a loopable background so when it scrolls, I can seamlessly place the background at the end of the first, then loop between those two images.
- Feature 2: Collectable stardust
  - Will add hitboxes to images so when the player touches them, it both increases the player score and the stardust disappears.
- Feature 3: Asteroid kills player
  - Will add hitboxes to asteroid images so when the player touches them, it ends the game.
- Feature 4: Asteroids and stardusts travel from screen right to left.
  - Will randomly generate on y axis on the far right then decreases x value by scroll speed.

## Challenges
- Need to learn how to code an endlessly scrolling background
- Need to learn how to add collision to images
- Need to learn how to make an item/object disappear after being 'collected'
- Need to learn how to end the game after player touches certain objects
- Need to learn how to make moving hitboxes that track a moving object

## Outcomes
Ideal Outcome:
- The player is able to move around and must collect stardust to increase their score.
- Stardust is always randomly generated at the right of the screen and moves to the left before disappearing off screen.
- The background moves from right to left to give illusion of constant movement.
- Asteroids appear and behaves the same as stardust, but kills the player and ends the game when hit.

Minimal Viable Outcome:
- The player spawns in a game with stationary stardust spread throughout that they must collect.
- A set amount of stationary asteroids appear that they must avoid or it ends the game.
